# Campus exterior C19 (overview)

`campus-exterior-c19.glb` is the polished campus overview exterior of Plan 4. It is byte-identical to `model/candidates/c19/campus-exterior.glb`, and its sources, fixes and approximations are in `model/candidates/c19/README.md`.

It uses the same frame and runtime transform as `campus-exterior.glb` (C5): translation `(0, 3.5, 0)`, scale 1, no rotation. It is for the overview only: not navigable, no collisions. C5 stays here as history.
